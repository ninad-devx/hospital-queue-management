# Hospital Queue Management System

A web-based application for managing hospital patient queues efficiently.

## Features
- Patient token generation
- Department-wise queue management
- Real-time queue tracking
- FastAPI backend
- Simple frontend interface

## Tech Stack
- Python
- FastAPI
- SQLAlchemy
- SQLite/MySQL
- HTML
- CSS
- JavaScript
